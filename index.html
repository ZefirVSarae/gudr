🎮 Ruffle SWF Player (offline, JS enabled)

Выберите SWF-файл, вставьте ссылку или перетащите файл в окно
Работает без сервера — откройте index.html двойным кликом.
Ruffle подключается из локальной папки ruf/.
allowScriptAccess: true включён — SWF может обращаться к JS.
При загрузке по ссылке возможны ограничения CORS на стороне сайта-источника.
